# Independent design review (checkpoint, step 12)

A fresh general-purpose subagent was given only the brief: "Look at the screenshots in
evidence/phase1/review and docs/DESIGN.md. List the 10 most important visual or UX problems, most
serious first, with the page and a concrete fix."

| #   | Finding (summary)                                                                             | Decision     | What changed                                                                                                                                                                             |
| --- | --------------------------------------------------------------------------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Mobile cart: remove control is a small unlabeled bin icon                                     | Rejected     | It is already a 44×44 px button with `aria-label="Remove {name} from cart"`, and removal already shows an Undo toast. The icon-only form saves space at 390 px; desktop shows the label. |
| 2   | "$44.00" in Fraunces reads as struck-through (crossbars of the 4s join)                       | Fixed        | Large prices now use DM Sans (tabular) instead of the display serif, so no price can be mistaken for a "was" price.                                                                      |
| 3   | Product breadcrumbs inconsistent ("Shop > Home > …"); category "Home" looks like the homepage | Fixed        | All product pages use "Home > Shop > {Category} > Product"; the category is renamed "Home & Living" (slug unchanged).                                                                    |
| 4   | Two search boxes on desktop catalog                                                           | Fixed        | Header search is hidden on /products, where the page search drives the grid.                                                                                                             |
| 5   | Search heading/intro generic; empty state only has Reset                                      | Fixed        | H1 is now `Results for "…"`, intro says what is being searched, empty state lists the four categories plus Reset.                                                                        |
| 6   | Disabled "Checkout coming in Phase 2" is the biggest button; add savings                      | Partly fixed | The disabled button is a hard requirement of the brief, so it stays. Added a "Sale savings" line to the order summary.                                                                   |
| 7   | "Explore the kitchen" reads as plain text                                                     | Fixed        | Now the secondary (outlined) button.                                                                                                                                                     |
| 8   | Mobile catalog search placeholder truncated                                                   | Fixed        | Placeholder shortened to "Search" (the field has a visible "Search" label).                                                                                                              |
| 9   | Out-of-stock items look like everything else; shown as recommendations                        | Partly fixed | Out-of-stock card images are muted, and "You may also like" excludes them. Not sorted last: that would break the "Newest" sort the user picked.                                          |
| 10  | Help & about page centred in a narrow column, breaking the left grid                          | Fixed        | Content now starts at the standard container gutter (reading width kept). Footer links already jump to section ids (`/info#returns` etc.).                                               |
| –   | Pagination arrows < 44 px on mobile                                                           | Rejected     | They are `size-11` (44×44) links; verified in the markup.                                                                                                                                |
| –   | Content shows through the scrolled header                                                     | Fixed        | Header background raised to 95–98 % opacity.                                                                                                                                             |
| –   | Product pages do not highlight their category in the nav; stepper/button height mismatch      | Not changed  | Minor; noted as known polish items.                                                                                                                                                      |
